# Explainable-RAG-Optimization

An explainable framework for optimizing prompts and retrieval strategies in Retrieval-Augmented Generation (RAG) systems.

## Objectives

- Build a RAG pipeline
- Generate prompt variants automatically
- Evaluate prompts across benchmark datasets
- Optimize retrieval parameters
- Explain performance gains using SHAP

## Tech Stack

- Python
- Hugging Face Transformers
- Sentence Transformers
- FAISS
- SHAP
- Pandas
- NumPy
